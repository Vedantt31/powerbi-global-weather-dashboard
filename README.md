# 🌍 Global Weather Summary Dashboard (Power BI)

## 📌 Overview
This repository contains an interactive **Power BI dashboard** that visualizes and analyzes global weather conditions using a publicly available Kaggle dataset. The dashboard highlights temperature extremes, rainfall, snowfall, sunshine duration, and geographic distribution across countries.

The project focuses on applying **data visualization best practices** and **analytical storytelling** using Power BI.

---

## 📊 Dashboard Features
- Maximum temperature comparison by country (°C)
- Minimum temperature comparison by country (°C)
- Rainfall analysis across countries (mm)
- Snowfall distribution (mm)
- Sunshine duration comparison (hours)
- Geographic map showing countries and their capitals
- Sorted visuals and readable labels for clarity
